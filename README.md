# 🎮 Somnia

Bienvenido a **Somnia**, nuestro proyecto de videojuego 🚀

Este repositorio está hecho para que trabajemos en equipo usando **GitHub Desktop**, incluso si nunca has usado Git antes.

👉 Este documento te va a guiar **desde cero**:

* Cómo instalar GitHub Desktop
* Cómo descargar el proyecto
* Cómo trabajar sin romper nada
* Qué hacer todos los días

---

# 🧠 Antes de empezar (muy importante)

Si solo lees una cosa, que sea esta:

## ⚠️ REGLA DE ORO

👉 **SIEMPRE haz `Pull` antes de empezar a trabajar**

👉 **SIEMPRE haz `Push` cuando termines**

---

2. Ve a:


4. Elige dónde guardarlo en tu computadora

```
readmeAssets/clone-repo-button.jpg
```

4. Ábrelo

```
readmeAssets/unity-open-project.jpg
```

# 🔁 4. Flujo de trabajo (LO QUE HARÁS SIEMPRE)

## 🔹 Antes de trabajar

1. Abre GitHub Desktop
2. Selecciona el repo **Somnia**
3. Haz:

👉 `Fetch origin`
👉 `Pull origin`

📸 (Imagen sugerida)

```
readmeAssets/pull-button.jpg
```

---

## 🔹 Trabaja normalmente

* Abre Unity
* Haz tus cambios
* Programa, diseña, lo que sea

---

## 🔹 Cuando termines

1. Guarda TODO en Unity
2. Regresa a GitHub Desktop

Verás los archivos modificados

📸 (Imagen sugerida)

```
readmeAssets/changes-list.png
```

---

## 🔹 Hacer commit

1. Escribe un resumen claro:

Ejemplos:

* `Agrega movimiento del jugador`
* `Corrige bug en enemigo`
* `Mejora iluminación`

❌ NO pongas:

* `cambios`
* `update`
* `aaa`

2. Haz clic en:
   👉 `Commit to main`

📸 (Imagen sugerida)

```
readmeAssets/commit-button.png
```

---

## 🔹 Subir cambios

Haz clic en:

👉 `Push origin`

📸 (Imagen sugerida)

---

# 🔄 Resumen rápido

## 🟢 Siempre haz esto:

```
Pull → Trabajar → Commit → Push
```

---

# ⚠️ Reglas del equipo

## 1. NO trabajes sin hacer Pull

Puedes romper el proyecto.

---

## 2. NO trabajen en la misma escena

Unity odia eso 😃

Ejemplo:

* Si alguien está en `MainScene`, no la toques

---

## 3. AVISA qué vas a modificar

Ejemplo:

> Voy a trabajar en el sistema de combate

---

## 4. Haz commits claros

Tu commit debe decir qué hiciste.

---

## 5. Sube cambios seguido

No te quedes con cambios solo en tu PC.

---

# 📁 Qué archivos NO tocar

NO subas cosas como:

* `Library/`
* `Temp/`
* `Logs/`
* `Obj/`

(Si ves algo raro, pregunta antes)

---

# 💥 Problemas comunes

## ❌ No te deja hacer Push

Haz esto:

1. Fetch
2. Pull
3. Intenta Push otra vez

---

## ❌ Conflictos

Si aparece algo raro:

👉 NO toques nada
👉 Pregunta

---

## ❌ Unity rompió algo

* Asegúrate de haber hecho Pull
* Asegúrate de tener la versión correcta

---

# 🧪 Ejemplo real

## Lore va a trabajar:

1. Abre GitHub Desktop
2. `Fetch`
3. `Pull`
4. Abre Unity
5. Trabaja
6. Guarda
7. Commit → `Agrega sistema de inventario`

✔️ Perfecto
